# Java 프로그래밍 시작하기

> Java 기초 학습 기록 — 노션 내용 정리 예정

## 개념 정리

### 1. Java 소개 및 환경 설정

- Java는 객체지향 기반의 범용 언어로, **"Write Once, Run Anywhere"** 원칙에 따라 OS에 상관없이 동일하게 동작한다.
- 플랫폼 독립성의 원리: `.java` → 컴파일 → **바이트코드**(`.class`) 생성 → 각 OS별 **JVM**이 바이트코드를 해석/실행. JVM을 "통역기", 바이트코드를 "번역된 원고"에 비유하면 이해하기 쉽다.
- **JDK / JRE / JVM** 관계:
    | 구성 요소 | 역할 |
    | --- | --- |
    | JDK | 개발 도구 모음 (컴파일러 `javac`, 실행기 `java`, JRE 포함) |
    | JRE | 실행 환경 (JVM + 표준 라이브러리) |
    | JVM | 바이트코드를 실제로 실행하는 가상 머신 |
- Java 17은 2021년 출시된 **LTS(장기 지원)** 버전으로, 안정성과 호환성이 뛰어나 실무 표준으로 사용된다.
- 설치 확인: `java -version`, `javac -version`. 컴파일/실행 흐름은 `javac HelloWorld.java` → `java HelloWorld`.

### 2. 변수와 연산

- **변수**: 값을 저장하는 메모리 공간. Java는 **정적 타입 언어**이므로 선언 시 자료형을 반드시 명시해야 한다. (선언 = 자료형만 지정, 초기화 = 실제 값을 담는 행위)
- **기본 자료형(Primitive Type)** — 값 자체를 저장하며 스택(Stack)에 저장됨, null 불가능:
    | 자료형 | 크기 | 설명 |
    | --- | --- | --- |
    | byte/short/int/long | 1~8byte | 정수형 (기본은 `int`, 큰 범위는 `long`) |
    | float/double | 4/8byte | 실수형 (기본은 `double`) |
    | char | 2byte | 문자(Unicode) |
    | boolean | 1byte | true/false |
- **참조 자료형(Reference Type)** — 클래스, 배열, 인터페이스, enum, record 등. 값이 아니라 **객체의 주소(참조)**를 저장하며 스택(주소) + 힙(실제 객체) 구조를 가진다. null 가능, 여러 변수가 같은 객체를 공유할 수 있다.
    - 기본형이 스택에, 참조형이 스택+힙에 저장되는 이유: 기본형은 크기가 고정돼 있어 메서드 종료 시 즉시 정리되지만, 참조형(배열/객체)은 크기가 가변적이고 여러 곳에서 공유되며 생명주기가 메서드보다 길 수 있어 GC가 관리하는 힙이 필요하다.
- **연산자**: 산술(`+ - * / %`), 비교(`> < == !=`), 논리(`&& || !`), 대입(`+= *=` 등), 삼항(`조건 ? 참 : 거짓`).
- **형변환(Type Casting)**:
    - 묵시적(자동): 작은 타입 → 큰 타입, 데이터 손실 없음 (`int → double`)
    - 명시적(강제): 큰 타입 → 작은 타입, `(타입)` 명시 필요, 데이터 손실 가능 (`double → int`)

### 3. 조건문과 반복문

- **조건문**: `if / else if / else`로 분기하며, `switch`는 하나의 변수 값에 따라 여러 분기 중 하나를 선택할 때 더 간결하다 (각 `case`에 `break`가 없으면 다음 case로 계속 실행되는 fall-through에 주의).
- **반복문**:
    - `for`: 초기식/조건식/증감식이 있는 정해진 횟수 반복. 향상된 for문(`for (타입 변수 : 배열/컬렉션)`)은 인덱스 없이 순회할 때 사용.
    - `while`: 조건이 참인 동안 반복, 횟수가 정해지지 않은 경우에 사용.
    - `do-while`: 조건과 무관하게 **최소 1회** 실행 후 조건을 검사.
- **흐름 제어 키워드**: `break`(반복문 즉시 종료), `continue`(현재 반복만 건너뛰고 다음 반복으로 이동).

### 4. 배열

- 배열은 **같은 자료형의 데이터를 연속된 메모리 공간**에 저장하는 자료구조이며, **크기가 고정**된다. 인덱스는 항상 `0`부터 시작하는데, 이는 첫 요소 주소를 기준으로 `index * 자료형 크기`만큼 떨어진 위치로 요소 주소를 계산하기 때문(offset 방식)이다.
- 선언/초기화: `int[] numbers = new int[3];`(0으로 자동 초기화) 또는 `int[] scores = {90, 80, 70};`. 기본값은 숫자 `0`, `boolean` `false`, 참조형 `null`.
- 유효 범위를 벗어난 인덱스 접근 시 `ArrayIndexOutOfBoundsException` 발생.
- **2차원 배열**: `int[][] matrix = {{1,2,3},{4,5,6}};` 형태로 행/열 구조 표현, 중첩 for문으로 순회.
- **얕은 복사 vs 깊은 복사**:
    - 얕은 복사(`int[] copy = original;`): 배열은 참조형이므로 주소값만 복사됨 → 두 변수가 같은 배열(객체)을 공유해서 한쪽 수정이 다른 쪽에도 영향을 준다.
    - 깊은 복사: 새 배열을 만들어 요소를 개별 복사 → 원본과 완전히 독립적. 방법은 수동 for문 복사, `Arrays.copyOf()`(가독성 좋고 실무에서 가장 많이 사용, 부분 복사도 가능), `System.arraycopy()`(메모리 블록 단위라 대량 데이터에 빠름).
- 유용한 API: `배열.length`(길이), `Arrays.toString(arr)`(문자열 변환), `Arrays.sort(arr)`(정렬).
