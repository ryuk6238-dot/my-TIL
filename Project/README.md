## 정리할 것

- **기술 선택 근거** — 왜 이 기술을 썼는가. "부트캠프에서 배워서"는 답이 아님
- **트러블슈팅** — 막혔던 지점, 원인, 해결 방법, 다시 하면 어떻게 할 것인가
- **구조 설명** — 요청이 들어와서 응답이 나가기까지의 흐름을 3분 안에 설명하기
- **한계와 개선점** — "트래픽이 10배면 어디가 먼저 터지나요"에 대한 답
